Supabase là nền tảng backend mã nguồn mở xây trên PostgreSQL (cloud hoặc tự host). Khả năng: Database Postgres; auto API REST (PostgREST) và GraphQL; Auth (email/mật khẩu, magic link, OTP, OAuth, SSO/SAML, MFA, JWT); Row Level Security; Storage (file, CDN, biến đổi ảnh); Realtime (thay đổi DB, broadcast, presence); Edge Functions (TypeScript/Deno); Vector/AI (pgvector, RAG); Cron & Queues (pg_cron, hàng đợi trong Postgres). Đi kèm: Studio, CLI + local dev (Docker, migration, branching), client libraries (JS/TS, Flutter, Swift, Kotlin, Python), connection string + pooler Supavisor, backup/PITR/read replicas (gói trả phí), MCP server. Use case: MVP/SaaS, app mobile/web, realtime, AI/RAG, backend nội bộ. Lưu ý: phải bật và viết đúng RLS; logic phức tạp cần Edge Functions/server riêng; gói free bị giới hạn (tạm dừng khi không hoạt động, hạn mức DB/storage/bandwidth); dựa trên Postgres nên ít bị khóa nhà cung cấp. Giá/giới hạn nên kiểm tra tại supabase.com/pricing.
